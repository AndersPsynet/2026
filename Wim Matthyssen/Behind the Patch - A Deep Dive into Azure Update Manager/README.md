# Behind the Patch: A Deep Dive into Azure Update Manager

**Speaker(s):** Wim Matthyssen

## Summary

A deep dive into managing updates for Azure and Azure Arc-enabled Windows and Linux servers with Azure Update Manager. Topics include periodic assessment, maintenance configurations, dynamic scopes, patch orchestration, and managing Azure Connected Machine agents and extensions.

## Notes

Only the slides are included; no separate demo scripts are supplied. Commands shown in the slides can change server management and patching settings. Review them before use and try them in a test environment. Azure services and Arc-enabled server management may incur charges; check current pricing before following along.
