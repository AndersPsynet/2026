# Microsoft Foundry for IT Pros: From Zero to Your First Production AI Agent

**Speaker(s):** Jannik Reinhard and Florian Salzmann

## Summary

A practical introduction to Microsoft Foundry for IT professionals: building a policy assistant, connecting knowledge and tools, and preparing agents for production with identity, network controls, guardrails, monitoring, and cost management.
