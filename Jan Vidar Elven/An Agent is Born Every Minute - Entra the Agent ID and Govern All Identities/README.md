# An Agent is Born (Every Minute) - Entra the Agent ID and GOVERN All Identities!

**Speaker:** Jan Vidar Elven

**Event:** NIC 2026, Oslo — 13.-15. October 2026

## Summary

You might have picked up on Entra Agent ID or Agent 365, and if you have been using Copilot, Azure Foundry or similar AI services in your tenant, you might already have thousands of agents in your organization(!) And it's increasing day by day. Where do you go from here? I work as an Identity Architect and have worked extensively with governing and securing user identities, privileged identities & workload identities in my company's and my customers' tenants, now I'm working on applying the same lifecycle management, security and governance controls for agent identities. Join me in this session for a practical approach to discover, protect and govern ALL identities in your tenant using the last updates for Entra Agent ID and Agent 365 with Security and Governance solutions in Microsoft Entra.

## Running the demos

The demos are based on the Public Microsoft Repository for Entra Agent ID Samples: https://github.com/microsoft/entra-agentid-samples.

Follow the public demo repository's documentation for available scenarios,
prerequisites, supported tools and versions, setup, permissions, costs and cleanup.
Check each scenario's documented status before running it; these slides do not
establish that every scenario is complete or ready for your environment.

Use a nonproduction lab and placeholder credentials. Review commands before
execution, obtain approval for changes or fault injection, and follow the
repository's cleanup instructions to remove provisioned resources and avoid
ongoing charges.
