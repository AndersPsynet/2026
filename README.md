# NIC 2026 - Speaker Materials

Slides, demos, code, and other resources from the **Nordic Infrastructure Conference (NIC) 2026**.

[Conference website](https://www.nicconf.com/) | [NIC 2025 materials](https://github.com/nordicinfrastructureconference/2025) | [Contribution guide](CONTRIBUTING.md)

## For attendees

Browse the folders by speaker name, then session title. Each session's README describes the available materials, prerequisites, and related links.

Materials are added by speakers and may arrive at different times. If something is missing, please contact the speaker or [open an issue](https://github.com/nordicinfrastructureconference/2026/issues).

Demo code is provided for learning, not as production-ready guidance. Review scripts before running them, use a test environment, and check for any cloud costs.

## For speakers

1. [Fork this repository](https://docs.github.com/en/get-started/quickstart/fork-a-repo).
2. Create a folder with your name and a subfolder for each session title, following the layout below.
3. Add your materials and a session README. You can copy the [session README template](templates/session/README.md).
4. [Open a pull request](https://github.com/nordicinfrastructureconference/2026/compare) to this repository's `main` branch.

Alternatively, email your materials or download links to [program@nicconf.com](mailto:program@nicconf.com), and the conference program manager will help upload them. Contributions are published under the MIT license; confirm that you have permission to share everything you submit.

```text
Speaker Name/
    Session Title/
        README.md
        slides.pdf
        slides.pptx
        demos/
            demo.ps1
    Another Session Title/
        README.md
        demos.zip
```

This is an example layout, not a list of confirmed speakers or sessions. Use the same speaker and session names as the conference program. For joint sessions, use a shared folder such as `Speaker One - Speaker Two`.

PDF slides are encouraged; the original slide file is welcome too. Demo source files are preferred for easy browsing, but a ZIP archive is also welcome. For recordings, large files, or externally maintained projects, add links to the session README.

See [CONTRIBUTING.md](CONTRIBUTING.md) for upload options, file-size limits, and the submission checklist.
